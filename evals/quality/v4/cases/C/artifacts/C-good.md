链式关系来自这三页：

- 条件熵：H(Y|X) = H(X,Y) - H(X)（[[条件熵]]）
- 联合熵：H(X,Y) = -Σ_x Σ_y P(x,y) log2 P(x,y)（[[联合熵]]）
- 信息熵：H(X) = -Σ_x P(x) log2 P(x)（[[信息熵]]）

把条件熵的定义移项可得（推导）：

H(X,Y) = H(X) + H(Y|X)

同理，交换 X 与 Y：

H(X,Y) = H(Y) + H(X|Y)

直观地说：联合不确定性 = 一个变量的不确定性 + 已知这个变量之后另一个变量剩下的不确定性。
