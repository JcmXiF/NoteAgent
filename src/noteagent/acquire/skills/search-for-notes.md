# 为人记笔记而搜

目标不是写完一篇综述，而是列出**足够交叉补充**的候选，交给人勾选。

## 怎么搜

1. 第一次查询用主题原词（例如 `KL散度`），不要一上来拆成多类来源分别搜。
2. 先看搜索引擎首页：角度是否互相补充、重要说法是否被反复提到、定义有没有着落。
3. 需要时再换一个互补词（中英、别名、常见写法），不要为了凑数量穷举。
4. 讲解类文章（论坛、教程站）往往适合建立整体图景；开若干篇是为了角度不同，不是完成配额。
5. 百科类来源适合核对概念与定义。清单里已经缺这块时，再读 `encyclopedia-gap` 并考虑 `wikipedia_lookup`。
6. 论文、教材、长推导：仅当用户意图明确要求深入时再考虑。本步没有论文工具。

## 不要做的

- 不要规定必须 N 篇讲解、1 篇百科、0 篇论文。
- 不要把知乎、CSDN 的流量写成代码里的加分。
- 不要抓正文、不要写入 `raw/` 或 `wiki/`。
- 视频、图片可以记在日后的候选里并标「暂不获取」，本步不处理。
